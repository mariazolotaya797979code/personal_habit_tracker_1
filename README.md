# Вершина

Локальный трекер привычек по ТЗ и референсу: силуэт победителя на горном пике на рассвете.

Это не сайт в интернете, а приложение на устройстве. Его можно упаковать в ZIP, передать через любой мессенджер, распаковать и пользоваться без облака. Данные остаются только на этом компьютере, планшете или телефоне.

Настроение — победа над собой: золото рассвета, глубокий синий, просторные экраны. Фон и акценты меняются каждый день недели.

Подробный запуск для пользователя — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Как это устроено

- Один владелец на устройство: первый регистрируется своим логином и паролем, дальше только вход.
- Всё хранится локально в браузере. В ZIP только программа — без привычек и пароля.
- На новом устройстве хранилище пустое: первый, кто откроет приложение, становится владельцем.
- Формат — PWA: ставится иконкой на компьютер, планшет и телефон, не ломается в ZIP, работает офлайн.
- Excel собирается на устройстве. Письмо открывает почтовый клиент — файл нужно приложить вручную.

Стек: React 19, Vite, TypeScript, Tailwind, Recharts, SheetJS. Сборку на Windows открывает `start.bat`, на macOS и Linux — `start.sh`.

## Разработка

```bash
npm install
npm run assets
npm run dev
```

Откроется http://localhost:5173.

| Команда | Что делает |
|---|---|
| `npm run build` | Сборка в `dist/` |
| `npm run preview` | Проверка сборки |
| `npm test` | Тесты |
| `npm run pack` | Готовая папка `release/` для передачи через мессенджер |

Для повседневного использования на Windows достаточно двойного щелчка по `start.bat`.
